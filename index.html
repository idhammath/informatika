Linear Search (Pencarian Berurutan)

Memeriksa setiap elemen dalam array satu per satu dari awal hingga akhir sampai elemen yang dicari ditemukan. Cocok untuk data yang sedikit atau tidak terurut.

Kompleksitas Waktu: O(N) - N adalah jumlah elemen.

Binary Search (Pencarian Bagi Dua)

Mencari dengan membagi array menjadi dua bagian. Memeriksa nilai tengah, jika target lebih kecil, cari di sebelah kiri. Jika lebih besar, cari di kanan. Syarat mutlak: Data harus terurut!

Kompleksitas Waktu: O(log N) - Sangat cepat untuk data besar.
