PENGANTAR

Mengenal Pengurutan Data

Sorting (pengurutan) adalah proses mengatur sekumpulan data atau objek ke dalam urutan tertentu, misalnya dari terkecil ke terbesar (ascending) atau sebaliknya (descending).

Apa itu Sorting?

Proses menyusun elemen data secara berurutan berdasarkan nilai dari kunci (key) masing-masing elemen.

KONSEP

Konsep Dasar

01

Array

Struktur data yang menyimpan sekumpulan elemen dengan tipe yang sama.

02

Indeks

Posisi suatu elemen di dalam array, biasanya dimulai dari 0.

03

Pertukaran (Swap)

Proses menukar posisi dua buah elemen dalam struktur data.

04

Kompleksitas Waktu

Ukuran seberapa efisien sebuah algoritma berjalan berdasarkan jumlah data.

05

Pseudocode

Cara penulisan algoritma yang menyerupai bahasa pemrograman tingkat tinggi.

06

Nested Loop

Perulangan di dalam perulangan, sering digunakan dalam algoritma sorting.

ALGORITMA

Comparison Sort

Bubble Sort

Bandingkan elemen bersebelahan, tukar jika urutan salah.

O(n²)

Selection Sort

Cari elemen terkecil, tempatkan di posisi terdepan.

O(n²)

Insertion Sort

Sisipkan elemen ke posisi yang tepat pada bagian array yang sudah terurut.

O(n²)

Merge Sort

Bagi array menjadi dua, urutkan masing-masing, lalu gabungkan.

O(n log n)

Quick Sort

Pilih pivot, partisi array, lalu urutkan masing-masing bagian.

O(n log n)

Heap Sort

Ubah array menjadi struktur heap, lalu ambil elemen terbesar satu per satu.

O(n log n)

ALGORITMA

Linear / Non-Comparison Sort

Counting Sort

Menghitung jumlah kemunculan setiap nilai unik.

Radix Sort

Mengurutkan digit per digit, dari paling tidak signifikan.

Bucket Sort

Membagi elemen ke dalam ember dan mengurutkan tiap ember.

Stabilitas

Algoritma stabil menjaga posisi awal untuk nilai yang sama.

In-Place Sorting

Tidak memerlukan memori tambahan yang signifikan.

Penggunaan Memori

Space complexity untuk menyimpan data sementara saat sorting.
